# FuzzAgent Harnesses

These harnesses were generated by **FuzzAgent** in five independent 24-hours trials and used to evaluate **FuzzAgent**'s performance in our [paper](nop). To facilitate the evaluation of additional 24-hours dedicated AFL++ Fuzzings, we encapsulate each generate harness by [C++ namespace](https://en.cppreference.com/cpp/language/namespace) block to mitigate the [name conflict](https://www.geeksforgeeks.org/cpp/resolve-name-conflict-in-cpp/) issue in LLM-generated harnesses.

To compile these harnesses into one fuzzer for fuzzing:

```
$ CXX=clang++ # or afl-clang-lto++, afl-clang-fast++ or other fuzzing engine
$CXX -fsanitize=fuzzer -I<path_to_include> *.cpp -o fuzzer  -DFUZZING_BUILD_MODE_UNSAFE_FOR_PRODUCTION -Wl,--allow-multiple-definition -Wl,--start-group <path_to_lib>/*.a -Wl,--end-group
```

Note:
- We removed the harnesses that triggered genuine library bugs confirmed by developers to provide enough durations for developers to take necessary actions to mitigate the possible negative effects.

- We used the `-Wl,--allow-multiple-definition` flag to let the compiler choose one implementation automatically when detected multiple definitions. This could introduce unexpected results, such as false positives or missing crashes. If you don't expect this side effect, please remove this flag and fix the conflicts manually.
